# Database Performance Predictor
This project predicts database query response time using machine learning models.

## Description
A synthetic dataset of 5,000 queries was generated using realistic workload and system features. 
Exploratory Data Analysis was performed, followed by training of Linear Regression and Random Forest models.

## Files
- db_performance_predictor.ipynb : Main notebook containing data generation, analysis, model training and evaluation.

## Models Used
- Linear Regression
- Random Forest Regressor

## Tools
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn
